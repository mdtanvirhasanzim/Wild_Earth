# Wild Earth — Natural Photography Portfolio

A complete multi-page photography portfolio built with HTML5, CSS3 and vanilla JavaScript.

## Run
Open `index.html` in a browser. No build step is required.

## Pages
- index.html
- about.html
- gallery.html
- collections.html
- journal.html
- article.html
- contact.html

## Features
Responsive navigation, scroll reveal, parallax hero, gallery filtering, fullscreen lightbox with keyboard controls, contact/newsletter validation, scroll progress, back-to-top, accessibility basics, SEO metadata, and reduced-motion support.

## Images
Demo photography uses remote Unsplash image URLs. Replace these URLs with your own licensed photographs for production use.

## Customize
Change the photographer name, biography, statistics, contact details, social links, metadata and image URLs in the HTML files. Colors and typography are centralized in `css/style.css`.
